# Assistant Botanique 3.5.1 Beta 9

Cette préversion corrige le parcours de contrôle d'humidité et d'arrosage dans l'écran **Aujourd'hui**.

## Contrôle du substrat

- lorsqu'un état **Humide** ou **Trempé** indique qu'aucun arrosage n'est nécessaire, le contrôle est désormais reporté automatiquement à la prochaine échéance adaptée ;
- la colonne **État** est recalculée immédiatement et affiche la nouvelle échéance, par exemple `Dans 2 j`, au lieu de rester sur `Aujourd'hui` ;
- un substrat **Sec** qui nécessite réellement un arrosage conserve la plante sélectionnée afin que l'utilisateur puisse confirmer l'action avec **Arrosé** ;
- le bouton manuel **Reporter le contrôle** reste disponible comme solution explicite lorsque cela est pertinent.

## Progression entre les plantes

- après un contrôle terminé sans arrosage, l'écran sélectionne automatiquement le prochain contrôle d'humidité d'une autre plante ;
- après validation d'un arrosage, l'écran passe également à la prochaine plante à contrôler ;
- les tâches d'un autre type, comme la fertilisation, ne sont pas prises à tort pour le prochain contrôle de substrat ;
- lorsqu'il ne reste plus de contrôle d'humidité dans les sept prochains jours, l'interface l'indique clairement.

## Installation

La Release publie l'installateur direct `AssistantBotanique-Setup-3.5.1-beta.9.exe` ainsi que son fichier SHA-256. L'installateur est construit, installé, exécuté puis désinstallé automatiquement sous Windows avant publication.
