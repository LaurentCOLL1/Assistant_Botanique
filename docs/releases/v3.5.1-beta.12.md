# Assistant Botanique 3.5.1 Beta 12

Cette préversion corrige l'affichage de la nouvelle icône sur les raccourcis Windows.

## Raccourci du Bureau

- le raccourci du Bureau ne dépend plus implicitement de l'icône intégrée à l'exécutable ;
- un fichier ICO versionné est installé avec l'application et référencé explicitement par le raccourci ;
- le chemin d'icône change à chaque version, ce qui évite de réutiliser une ancienne entrée du cache d'icônes de l'Explorateur Windows ;
- le raccourci du menu Démarrer utilise la même icône explicite ;
- l'entrée de désinstallation reprend également cette icône.

## Validation renforcée

Le smoke test Windows crée désormais réellement le raccourci du Bureau. Il vérifie le fichier `.lnk`, sa cible, son `IconLocation`, l'existence de l'ICO versionné, le lancement de l'application, puis la suppression du raccourci lors de la désinstallation.
