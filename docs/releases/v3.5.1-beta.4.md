# Assistant Botanique 3.5.1 Beta 4

Cette préversion corrige la détection des mises à jour et enrichit l'onglet **Substrats**.

## Mises à jour

- la vérification consulte maintenant toutes les Releases publiées, y compris les préversions ;
- les versions alpha, bêta, RC et stables sont comparées dans le bon ordre ;
- les brouillons GitHub sont ignorés ;
- la meilleure Release disponible est sélectionnée même si GitHub ne la considère pas comme `latest`.

## Mode simple

- l'onglet **Substrats** est maintenant disponible dans le mode simple.

## Variantes de substrat

Chaque fiche du catalogue propose désormais trois choix :

1. **Synthèse des variantes**, placée en premier et calculée comme une moyenne pondérée des deux autres compositions ;
2. une première composition horticole ;
3. une seconde composition complémentaire.

Chaque variante possède au moins quatre sources concordantes correspondant au groupe botanique et au type de culture. L'application indique explicitement qu'il s'agit d'un consensus par groupe botanique et non d'une validation manuelle individuelle de chacune des milliers d'espèces du catalogue.

La totalité du catalogue est auditée automatiquement : nombre de variantes, somme des ratios, ingrédients reconnus, conflits avec les interdits et nombre de sources distinctes.

Cette version reste une préversion. Il est recommandé de conserver les sauvegardes automatiques activées.
