# Assistant Botanique 3.5.1 Beta 3

Cette préversion ajoute une visionneuse agrandie pour les photos affichées dans l'onglet **Collection**.

## Nouvelle visionneuse photo

- les vignettes de **Dernières photos** sont maintenant cliquables ;
- un clic ouvre la photo dans une fenêtre dédiée ;
- l'image s'adapte automatiquement à la taille de l'écran et à la fenêtre ;
- les proportions et la résolution native sont conservées ;
- la fenêtre peut être redimensionnée ;
- la légende et la date de la photo restent visibles ;
- la touche **Échap** et le bouton **Fermer** permettent de quitter la visionneuse ;
- les vignettes peuvent également être ouvertes au clavier avec **Entrée** ou **Espace**.

## Compatibilité

Le masquage et l'affichage des dernières photos, le choix du nombre de vignettes et le panneau de détails redimensionnable restent compatibles avec cette visionneuse.

Cette version reste une préversion. Il est recommandé de conserver les sauvegardes automatiques activées.
