# Assistant Botanique 3.5.1 Beta 10

Cette préversion rend le parcours de contrôle d'humidité cohérent entre les onglets **Aujourd'hui** et **Collection**.

## Onglet Collection

- les colonnes **Prochain contrôle** et **Statut** utilisent désormais l'échéance réellement reportée après un contrôle d'humidité ;
- un substrat **Humide** ou **Trempé** qui ne nécessite pas d'arrosage reporte automatiquement le prochain contrôle et met immédiatement le tableau à jour ;
- le bouton historique **Enregistrer un arrosage** est remplacé par le même parcours **Sec / Humide / Trempé → Arrosé** que dans l'onglet Aujourd'hui ;
- un arrosage ne peut donc plus contourner le contrôle préalable de l'humidité ;
- lorsqu'un substrat **Sec** nécessite un arrosage, la plante reste sélectionnée jusqu'à validation avec **Arrosé** ;
- après un contrôle sans arrosage ou après un arrosage validé, la sélection passe à la prochaine plante dont le contrôle est arrivé à échéance ;
- le panneau de détails affiche lui aussi l'échéance effective afin d'éviter toute contradiction avec le tableau.

## Validation

La modification est couverte par des tests de régression sur le calcul de l'échéance effective, le maintien d'un contrôle nécessitant un arrosage et le choix de la prochaine plante à traiter. L'installateur Windows est construit, installé, exécuté puis désinstallé automatiquement avant publication.
