# Assistant Botanique 3.5.1 Beta 6

Cette préversion ajoute enfin un installateur Windows directement utilisable par le vérificateur de mises à jour intégré.

## Mise à jour directe

- la Release contient un véritable fichier `AssistantBotanique-Setup-3.5.1-beta.6.exe` ;
- l'application détecte automatiquement cet asset, le télécharge et lance l'installation ;
- un fichier SHA-256 est publié à côté de l'installateur ;
- le dossier d'installation par défaut correspond à l'installation Windows historique : `%LOCALAPPDATA%\Programs\AssistantBotanique` ;
- les données personnelles restent conservées dans le dossier de données utilisateur séparé.

## Construction et validation

L'installateur est construit sous Windows avec PyInstaller et Inno Setup. Avant sa publication, le workflow :

1. construit l'application autonome ;
2. construit l'installateur ;
3. installe silencieusement le paquet dans un dossier temporaire ;
4. exécute l'application installée avec `--version` ;
5. vérifie le code de sortie ;
6. désinstalle le paquet de test ;
7. joint l'installateur validé à GitHub Releases.

Cette version reste une préversion. Windows peut afficher un avertissement SmartScreen tant que l'exécutable n'est pas signé avec un certificat de signature de code reconnu.
