# Assistant Botanique 3.5.1 Beta 11

Cette préversion adopte la nouvelle identité visuelle fournie pour **Assistant Botanique**.

## Nouvelle icône du programme

- le visuel plante + assistant est désormais l'icône officielle de la fenêtre principale ;
- la même identité est intégrée directement à `AssistantBotanique.exe` ;
- les raccourcis du menu Démarrer et du Bureau héritent donc de cette icône ;
- l'installateur Windows utilise lui aussi cette icône ;
- une source PNG optimisée est versionnée et un ICO multi-résolution est régénéré automatiquement pendant le build.

## Qualité et packaging

La source d'icône est vérifiée comme PNG carré valide. Les tests contrôlent également la génération du fichier ICO et les références utilisées par PyInstaller et Inno Setup. Comme pour les préversions précédentes, l'installateur Windows est construit, installé, vérifié puis désinstallé automatiquement avant publication.
