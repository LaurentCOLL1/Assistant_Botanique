# Assistant Botanique 3.5.1 Beta 1

Cette première préversion publique permet de tester l'application avant une version stable.

## Points forts

- gestion d'une collection de plantes avec historique des soins et photos ;
- nouveau parcours d'arrosage fondé sur l'état réel du substrat : sec, humide ou trempé ;
- recommandation d'arrosage adaptée aux données botaniques de chaque fiche ;
- compagnon mobile avec ajout de stock et lecture locale des codes-barres ;
- diagnostic photo local et prudent ;
- recettes personnelles de substrat ;
- sauvegardes automatiques et installation assistée des mises à jour ;
- outils avancés de suivi, d'infestation, de recherche et de planification.

## Correctif inclus dans cette bêta

- restauration de tous les titres de colonnes dans les onglets **Aujourd'hui** et **Collection** après l'ajout de la colonne **Humidité du substrat**.

## Statut bêta

Cette version est une préversion. Il est recommandé de conserver les sauvegardes automatiques activées et de signaler les anomalies rencontrées dans les issues GitHub.

Les archives de code source proposées automatiquement par GitHub sont destinées aux utilisateurs qui installent l'application depuis le dépôt. Les futurs installateurs Windows pourront être ajoutés aux versions suivantes.
