# Assistant Botanique 3.5.1 Beta 7

Cette préversion améliore la lecture du tableau de l'onglet **Aujourd'hui**.

## Nouvelle colonne

- une colonne **Nom scientifique** apparaît désormais entre **Plante** et **Soin / contrôle** ;
- le nom est récupéré depuis la fiche botanique associée à la plante ;
- les contrôles automatiques et les soins planifiés affichent tous deux cette information ;
- lorsqu'aucun nom scientifique n'est disponible, la cellule affiche **Non renseigné** ;
- les colonnes d'état, d'humidité du substrat et de détails restent correctement alignées.

## Installation

La Release contient l'installateur direct `AssistantBotanique-Setup-3.5.1-beta.7.exe` ainsi que son fichier de contrôle SHA-256. L'installateur est construit, installé, exécuté puis désinstallé automatiquement sur Windows avant publication.
