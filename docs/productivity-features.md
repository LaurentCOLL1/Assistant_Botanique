# Fonctions de productivité

## Aujourd'hui

Le tableau de bord réunit les contrôles d'humidité proposés par le moteur adaptatif et les soins planifiés pour les sept prochains jours. Les actions rapides enregistrent immédiatement le résultat dans l'historique de la plante.

## Calendrier et autres soins

Le calendrier mensuel affiche les contrôles adaptatifs et les tâches ponctuelles ou récurrentes : fertilisation, rempotage, taille, traitement, rotation du pot, nettoyage et observation. Une tâche terminée est transformée en événement de soin ; une tâche récurrente crée automatiquement sa prochaine occurrence.

## Recherche globale

`Ctrl+K` ouvre une recherche couvrant la collection et le catalogue. Les filtres portent sur la famille, l'emplacement, l'échéance et la présence d'une photo.

## Export et import

L'onglet **Données & système** exporte la collection en JSON ou CSV. Le JSON conserve l'historique et les tâches planifiées. Le CSV facilite la modification dans un tableur. Avant chaque import, l'application crée une archive `.botanique` de sécurité, puis propose soit une fusion, soit un remplacement complet.

## Diagnostic guidé

Le diagnostic pose six questions successives et classe plusieurs hypothèses prudentes à partir des réponses et du contexte de la plante. Il ne confirme jamais une maladie.

## Mode simple

Le menu **Affichage** permet de basculer entre :

- le mode simple : Aujourd'hui, Collection, Recherche, Calendrier, Journal, Catalogue et Données ;
- le mode avancé : tous les outils de révision, substrats, diagnostic et soins adaptatifs détaillés.
